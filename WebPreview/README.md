# Windows 瀏覽器預覽

直接以 Edge 或 Chrome 開啟 `index.html` 即可使用；不需要安裝 Python、Node.js 或 Xcode。

此版從 Yahoo Finance 讀取日線資料，並在畫面標示最後交易日與資料來源；若瀏覽器的網路或跨網域設定阻擋請求，會顯示明確錯誤，且**不會以隨機或模擬價格替代**。兩張圖共用游標日期，移過任一圖表即顯示垂直參考線。畫面上的 K 線以收盤線搭配均線呈現，正式 iOS 版則保留完整 OHLC 資料結構。

「操作與新聞脈絡」卡會開啟該股票的 Google News 搜尋結果；新聞內容不會自動轉換為投資建議。

## 效能處理

- 游標參考線會以 `requestAnimationFrame` 合併重繪，不會在每個滑鼠事件重新計算圖表。
- 關閉圖表動畫、啟用排序資料正規化與自動略過多餘 X 軸標籤。
- 相同代碼與區間的行情資料會在頁面生命週期快取；均線使用 O(n) 滑動加總計算。
